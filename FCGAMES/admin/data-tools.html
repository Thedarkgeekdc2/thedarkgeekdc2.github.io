Import, Export & Backup

Move your custom questions safely between devices and keep a backup before major changes.

📶 About syncing between devices

All admin data (questions, topics, classes, subjects, settings) is saved only in this browser's local storage — there's no shared server, so changes made here don't automatically appear on another phone, tablet or computer. To move your changes to another device: Export here, then Import the same file on the other device — it merges in without deleting anything already there.

Import JSON

Adds questions to what you already have — never replaces or deletes existing content. New classes, subjects and topics found in the file are added automatically.

What format does this file need?

Either of these shapes works:

1. A single topic (same shape as the built-in topic files) — every question inherits class/subject/topic from the wrapper:

{
  "class": 3,
  "subject": "maths",
  "topic": "Multiplication Practice",
  "questions": [
    { "id": "mul101", "type": "mcq", "question": "7 × 8 = ?",
      "options": ["54","56","58","64"], "answer": "56", "difficulty": "easy" }
  ]
}

2. Several topics at once — a JSON array of objects shaped like above, or a full export/backup file (each question already carries its own class/subject/topic).

A brand-new class number or subject name that doesn't exist yet is created automatically so it shows up in the game — no need to add it in Classes & Subjects first.
