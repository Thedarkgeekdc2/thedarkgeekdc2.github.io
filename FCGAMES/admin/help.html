🎮 For Players

Playing the Game

Nine simple steps — from opening the app to seeing your score.

1

Open the app

Go to the website. You'll land straight on the home screen — no sign-up, no password needed to play.

2

Choose your Class

Tap the card for your class (grade). You'll only see the classes that have been set up.

3

Choose a Subject

Pick from the subjects shown for your class, like Maths or Hindi.

4

Pick a Topic

Each subject has several topics — like Addition, Shapes, or Time. Tap the one you want to practise.

5

Choose a Difficulty

Pick Easy, Medium, or Challenge depending on how confident you feel.

6

Answer by tapping

Every question is answered with a single tap — a picture, a word, or dragging a tile into place. You never need to type anything.

👆 Tap only — no typing, ever
7

Watch your progress

While you play, you'll see your score, how many lives you have left, your streak of correct answers, and a timer — depending on what your teacher has turned on.

8

See your result

At the end of the topic, a results screen shows how many you got right and how well you did.

9

Play again

Try the same topic again to beat your score, or go back and pick a new one. There's no limit — practise as much as you like!

🛠️ For Teachers

The Admin Panel

Tap any card below to open it up. This is where you add questions, manage topics, and change how the app looks.

🔑 Logging In ▾

Open the Admin Login page (there's a link at the bottom of the game screen). Enter the username and password given to you by whoever set up your app.

You'll stay logged in for a while automatically. If you leave the page idle for too long, it'll ask you to log in again — that's normal and keeps things safe.

Please note: if you're still using the starting password, ask whoever manages your website to change it to something private.
🏠 The Dashboard ▾

Once logged in, the Dashboard is your home base. It shows a card for every tool — tap any card to open that tool. Here's what each one does:

  • Question Builder — create a brand-new question
  • Question Library — see, search, edit, or remove existing questions
  • Classes & Subjects — add a new grade or subject
  • Topics — add or remove topics inside a subject
  • Images — check and reuse the pictures used in questions
  • Settings — change your school's name, colours, and game rules
  • Data Tools — bring in ready-made question files, or save a copy of your own work
➕ Adding a Question ▾

Open Question Builder from the Dashboard.

  1. Choose the Class, Subject, and Topic this question belongs to.
  2. Choose a question type — for example, a simple multiple-choice question, a True/False statement, matching pairs, dragging items into place, or a picture-based question.
  3. Type your question, then fill in the answer choices (or pairs, or items, depending on the type you picked).
  4. Mark which answer is correct.
  5. Watch the box on the side — it shows exactly how the question will look to a student, updated as you type.
  6. Tap Save. That's it — the question is ready to be played.
💡 Not sure which type to pick? Start with the simple multiple-choice type — it works for almost anything.
📚 Managing Questions ▾

Open Question Library to see every question you've added. You can:

  • Search by typing a word from the question
  • Filter by Class, Subject, or question type
  • Tap Edit to change a question, or Delete to remove it

A small picture icon next to a question means it has an image attached to it.

🏷️ Classes, Subjects & Topics ▾

Open Classes & Subjects to add a brand-new grade or subject — just type its name and tap Add. It will immediately show up as an option everywhere in the app.

Open Topics to add or remove a topic inside a class and subject — for example, adding "Fractions" under Class 3 → Maths.

🖼️ Images ▾

Open Images to see every picture currently used in your questions, with a quick check showing whether each one loads properly or is broken.

There's also a small tool to preview a picture from your own device and get a suggested name for it — handy when you're about to ask your website manager to add a new picture for you to use in a question.

🎨 Settings ▾

Open Settings to change:

  • Your school's name and footer message
  • The app's colour theme
  • Game rules — how many questions per round, how many lives, whether there's a timer, and points/streak settings
Good to know: changes you make here are saved on the device and browser you're using right now. Someone opening the app on a different phone or computer won't see your change until your website manager makes it permanent for everyone.
🔄 Data Tools ▾

Open Data Tools for three things:

  • Import — bring in a ready-made question file (someone may have prepared one for you)
  • Export — save a copy of the questions you've built, as a file you can keep
  • Backup / Restore — save everything at once, or bring it all back if something goes wrong
💡 There's a separate step-by-step guide for creating a whole set of questions automatically from a book chapter, using AI. Ask for it if you'd like a copy.
💡 Quick Tips

Good to Know

👆

Nothing to type, ever

Every question in the game is answered by tapping — never by typing an answer.

💾

Save copies often

Use Export or Backup in Data Tools regularly, so your work is never lost.

📱

Works on any device

Phone, tablet, or computer — the app adjusts itself to fit the screen.

🔒

Change the default password

If you're still using the starting admin password, ask to have it changed.

🌐

Some changes are per-device

Settings and questions you add stay on your device until made permanent by your website manager.

🔁

Practice has no limit

Students can replay any topic as many times as they like.

❓ Quick Answers

Frequently Asked Questions

Do students need to install anything?
No. It opens straight in a web browser, on any phone, tablet, or computer.
Do I need the internet to play?
Yes, the app loads over the internet each time you open it.
I added a question but a student can't see it. Why?
Questions you add are saved on your own device first. Ask your website manager to make them permanent so every student can see them.
Can I undo a mistake in the Admin Panel?
Yes — if you took a Backup beforehand, use Restore in Data Tools to bring everything back to that point.
I forgot the admin password. What now?
Ask whoever manages your website to look it up or reset it for you.
Can more than one teacher use the Admin Panel?
Yes, anyone with the password can log in from their own device.
