➕ Adding a new image

This app is hosted as plain static files (for example on GitHub Pages), so there's no upload button here that saves a file anywhere students can see. To add a picture: upload it into assets/images/<subject>/<folder>/ in the project (through GitHub's "Add file" or your code editor), then use that path in the Question Builder. Preview a file from your own device below to get a ready-made path first.
