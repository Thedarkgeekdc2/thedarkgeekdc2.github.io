Getting Started
System Overview

DAS is a QR-based smart attendance platform. Students carry signed QR cards that are scanned at school gates — attendance is recorded automatically, in real time.

🔄 How It Works — End to End
  1. Admin imports the student list. Each student is assigned a unique ID.
  2. A signed QR card is generated and printed for each student.
  3. Students scan their QR card at the gate when arriving or leaving.
  4. The system reads the time and automatically marks Present, Late, or Half-Day.
  5. Teachers and the Principal view live attendance on their dashboards.
  6. Reports can be downloaded as Excel files at any time.

Admin

  • Bulk import via Excel
  • Add & delete teachers

  • Data cleanup
👑
Principal
  • School-wide attendance view
  • Filter by class & section
  • Daily / Weekly / Monthly reports

  • View No-Class UIDs
  • Cannot import Excel
  • Cannot manage teachers
👩‍🏫
Teacher
  • Own class attendance only
  • Download own class report
  • Cannot view other classes
  • Cannot manage students

Excel Import

Import the entire school's student list at once using an Excel file. Multiple files and multiple sheets are supported in a single upload.

📋 How to Prepare the Excel File
Your .xlsx file needs these columns (names are case-insensitive):

PurposeAccepted Column NamesRequired?
Student IDuid · id · rfid · card_idYes
Student Namename · student name · full nameYes
Classclass · grade · std · standardYes
Sectionsection · sec · divOptional
Roll Numberroll · roll_no · rollnoOptional
📤 How to Import
  1. Go to the Students page.
  2. Click the Import Excel button.
  3. Select one or more .xlsx files.
  4. Click Upload — all sheets are processed automatically.
  5. A result summary shows records imported, updated, and skipped.
ℹ️
Same UID again → record is updated, no duplicate is created.
No Class column → system tries to detect it from the sheet name.
Row missing UID or Name → that row is skipped automatically.

Attendance
How Gate Scanning Works

Students hold their QR card in front of the scanner at the gate. The system reads the time and automatically decides the attendance status — no manual input needed.

1️⃣ First Scan — Entry
06:50 – 07:30 ✅ Present On-time entry — speaker says "Hello [Name]"
07:30 – 08:00 ⚠️ Late Late entry — speaker says "Late [Name]"
Any other time 🔧 Special Work Visiting for school duty — "For Special Work [Name]"
2️⃣ Second Scan — Exit
10:20 – 12:20 🌓 Half-Day Exit Early departure — "Half day [Name]"
12:20 – 17:00 🚪 Normal Exit Full-day exit — "Bye [Name]"
⛔ Rejected Scans
SituationVoiceResult
Tampered or invalid card"Invalid ID"No record created
Unreadable QR format"Invalid QR"No record created
Student already marked"Already marked [Name]"Duplicate blocked
Exit outside allowed window"Exit not allowed now"Exit blocked

Attendance
Manual Attendance Override

If a student's attendance was marked incorrectly or a scan was missed, Admin or Principal can correct it manually.

✏️ How to Override Attendance
  1. Go to Attendance Override from the dashboard menu.
  2. Select the date you want to correct (defaults to today).
  3. Filter by Class and Section.
  4. Find the student — their current status is shown alongside.
  5. Select the corrected status from the dropdown.
  6. Optionally add a reason or remark.
  7. Click Save — the change takes effect immediately.
⚠️
Every override is permanently recorded in the Audit Trail — who changed it, when, and why.
Attendance
Offline Mode

If the server is temporarily unreachable, the gate continues scanning and saves records locally. Nothing is ever lost.

📡 What Happens During a Network Outage
  1. Gate detects the server is unreachable.
  2. All scans are saved locally on the gate device.
  3. Voice feedback and status logic continue working normally.
  4. The gate checks for the server in the background every 60 seconds.
  5. Once the server is back online, all queued records sync automatically.
✅
Even if power cuts out or the network goes down — no attendance data is ever lost. The gate handles everything silently.

Reports & Logs
No-Class UIDs

When a card is scanned at the gate but its UID is not in the database, it is saved here for Admin review rather than being lost.

❓ What Are No-Class UIDs
A No-Class entry is created when an unknown card is scanned — the UID, date, and time are saved.

Common reasons:
— A new student joined but hasn't been added to the system yet
— An old or unregistered card was accidentally scanned
— A test scan was performed during setup
✅
Check this page regularly. If you recognise a UID, add the student via the Students page right away.

Account
Change Password

Any user — Admin, Principal, or Teacher — can update their own password at any time from the dashboard.

🔑 How to Change Your Password
  1. Click your name in the top-right corner of the dashboard.
  2. Select Change Password from the dropdown.
  3. Enter your current password.
  4. Enter and confirm your new password.
  5. Click Update Password — takes effect immediately.
⚠️
Choose a strong password. Avoid using your name or date of birth. You may be asked to log in again after the change.

Frequently Asked Questions
❓ A student scanned but it doesn't show on the dashboard
Refresh the page (F5). The dashboard is real-time but does not update automatically — a manual refresh is needed.
❓ A student's attendance status is wrong
Use Attendance Override to correct it. Select the date, find the student, pick the correct status, add a reason, and save.
❓ Some students are missing from the report
Check whether those students exist on the Students page. If not, add them manually or via Excel import, then run the report again.
❓ A teacher is seeing the wrong class
Admin should go to the Teachers page → Edit the teacher's account → correct the Class and Section → Save.
❓ Gate is scanning but attendance isn't appearing
The gate is likely offline and storing records locally. Once the network is restored, all queued records sync automatically. If the issue persists, contact the Admin.
❓ I forgot my password
Contact the Admin — they can reset your password and provide a temporary one.
